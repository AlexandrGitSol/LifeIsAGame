# LifeIsAGame

LifeIsAGame — это реализация классического клеточного автомата "Игра Жизнь" (Conway's Game of Life) с использованием C++ и библиотеки SFML для графического отображения.

## О проекте

При запуске программы открывается графическое окно с игровым полем, где в реальном времени происходит эволюция клеток согласно правилам "Игры Жизни". Проект демонстрирует работу с графикой через SFML и реализацию алгоритмов клеточных автоматов.

## Функциональность

- **Автоматическая эволюция** клеток по правилам Конвея
- **Визуальное отображение** игрового поля в реальном времени

## Правила игры

1. **Живая клетка** с 2 или 3 живыми соседями выживает в следующем поколении
2. **Живая клетка** с менее чем 2 или более чем 3 соседями умирает (от одиночества или перенаселения)
3. **Мёртвая клетка** с ровно 3 живыми соседями оживает
